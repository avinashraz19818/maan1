1) PROBLEM KYA THI (technical, short)
--------------------------------------------------------------------------------
Aapki screenshot / DevTools me:
    POST /developer-maruf/api/webapi/Login   ->  HTTP 503 Service Unavailable
    App ne modal dikhaya: "Service not available!"

App me status-code ka fixed message hota hai:
    500 -> "Server error!"      502 -> "Gateway error!"
    503 -> "Service not available!"    504 -> "Gateway time out!"
Matlab jo bhi asli error tha, wo chhup gaya — app sirf "503" dekhta hai.

503 ka source = developer-maruf/api/webapi/Login.php ka last catch block:

    } catch (Throwable $error) {
        error_log('[Login] ' . $error->getMessage());
        app_api_send(null, 8, 'Login service is unavailable', 503, 8);   <-- 503 yahan se
    }

Aapki site par GET request sahi JSON deti hai (maine live check kiya), matlab PHP,
database connection, app_settings — sab chal raha hai. Isliye error us try ke
andar wale DATABASE step me aa raha hai — yaani shonu_subjects (user table) wale
queries. PHP 8.1+ par mysqli har SQL error par exception throw karta hai, isliye
ek chhoti si schema problem bhi seedha 503 ban jati hai.

Sabse common wajah: legacy user table ke kuch column database me missing hain,
ya token column (akshinak) chhota hai aur usme naya JWT fit nahi hota
("Data too long for column 'akshinak'").
